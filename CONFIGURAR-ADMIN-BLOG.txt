ADMIN /BLOG - BOTÃO EXCLUIR ARTIGO

O pacote adiciona um botão vermelho "Excluir artigo" em cada post do /admin/blog/.

Para a exclusão funcionar em produção, configure estas variáveis na Vercel:

ADMIN_BLOG_TOKEN = uma senha/token forte que só você conhece
GITHUB_TOKEN = token do GitHub com permissão Contents: Read and write no repositório do site
GITHUB_OWNER = usuário ou organização dona do repositório
GITHUB_REPO = nome do repositório do site
GITHUB_BRANCH = main (opcional; se não informar, usa main)

Depois faça um novo deploy.

Ao clicar em "Excluir artigo", o admin pede o ADMIN_BLOG_TOKEN e a API remove:
- o arquivo HTML do artigo;
- o cadastro em data/blog-posts.json;
- o card do artigo em blog.html;
- a URL do sitemap.xml;
- a rota do artigo em vercel.json.

A exclusão acontece no GitHub e dispara o redeploy normal da Vercel.
