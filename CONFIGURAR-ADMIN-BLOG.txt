ADMIN BLOG — CONFIGURAÇÃO NA VERCEL

Para os botões "Subir ZIP e publicar" e "Excluir artigo" funcionarem, configure:

ADMIN_BLOG_TOKEN = senha/token que você escolher para o painel
GITHUB_TOKEN = token do GitHub com permissão de escrita no repositório
GITHUB_OWNER = usuário/organização dona do repositório
GITHUB_REPO = nome do repositório
GITHUB_BRANCH = main

Depois faça um novo deploy.

O painel fica em:
/admin/blog/

O upload aceita ZIPs com até aproximadamente 3,2 MB descompactados pelo painel.
Pacotes maiores devem ser enviados direto pelo GitHub.
