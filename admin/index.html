Backup completo do site

Baixa a branch main do GitHub e recria um ZIP portátil sem a pasta mpmv-main/. Ao extrair, os arquivos já ficam prontos para a raiz de outro repositório.

Importante: o backup contém os arquivos versionados no GitHub no momento do clique. Variáveis de ambiente, chaves da Vercel e segredos não entram no ZIP. O arquivo .env.example permanece como referência, mas valores reais precisam ser configurados novamente no novo ambiente.
