# Validação antes da publicação

## Identidade e escopo
- Pasta do repositório: `NPMV-Sitee` (nome técnico confirmado na conversa).
- Marca exibida no site: **Mais Persuasão, Mais Vendas (MPMV)**, preservando o projeto e o domínio existentes.
- Estrutura estática, sem dependências de framework.

## SEO da homepage
- [x] Um H1 principal.
- [x] Title e meta description exclusivos.
- [x] Canonical absoluto.
- [x] Open Graph + Twitter Card.
- [x] Schema.org Organization + WebSite.
- [x] Links internos para blog e artigo.
- [x] Sitemap e robots.txt.
- [x] Rotas antigas `/home` e `/artigo-seo` redirecionadas por 301, evitando conteúdo duplicado.

## SEO do artigo
- [x] Palavra-chave principal no title, H1, introdução, URL e subtítulos de forma natural.
- [x] Hierarquia H1 > H2 > H3.
- [x] Canonical e Article schema.
- [x] BreadcrumbList schema.
- [x] Imagem Open Graph 1200×630 e alt text.
- [x] Links internos para início/blog e CTAs de produto.

## Legibilidade
- [x] Largura de leitura limitada a 760 px.
- [x] Corpo 1.08rem, line-height 1.68.
- [x] Parágrafos curtos e subtítulos frequentes.
- [x] Português brasileiro conversacional, sem sequência de frases telegráficas.
- [x] Conceitos técnicos traduzidos para situações de funil e produção de conteúdo.

## Performance
- [x] Sem framework e sem bibliotecas externas.
- [x] Sem fontes externas.
- [x] JavaScript mínimo e carregado com `defer`.
- [x] CSS único.
- [x] Imagens locais e dimensões declaradas para reduzir CLS.
- [x] Cache longo para `/assets/` via Vercel.

## Conversão
- [x] CTAs em links azuis e em negrito, sem botões.
- [x] CTA do Guia aparece na homepage e no artigo.
- [x] CTA do curso aparece na homepage e no artigo.
- [x] CTAs surgem como continuação do conteúdo.
- [x] Sem depoimentos inseridos.
- [x] Uma ação principal por bloco.

## Checklist MPMV
- [x] Fonte de verdade e briefing respeitados.
- [x] Nível de consciência tratado antes da escrita.
- [x] Função da peça: SEO + consciência/consideração + conversão assistida.
- [x] Mudança de crença: de “preciso trocar o criativo” para “preciso revisar público, prova, oferta e sequência de argumento”.
- [x] Promessa da headline entregue no corpo.
- [x] Sem escassez inventada, números fabricados ou depoimentos não validados.
- [x] CTA compatível com o conteúdo.
- [x] Revisão de naturalidade e coerência concluída.
